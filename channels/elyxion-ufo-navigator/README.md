# Elyxion UFO Navigator 🛸🌍

Status: **CANDIDATE / NAVIGATION-ONLY / NOT CANON / NO EXECUTION AUTHORITY**

## Mission

Elyxion UFO Navigator is the top-level navigation layer for the Elyxion repository.

Its job is to understand the project **from above** without taking authorship away from the creator, without silently changing meaning, and without trying to become Global C0.

It answers:

- What exists?
- Where does it live?
- Where did it come from?
- What status and authority does it have?
- What is it connected to?
- What changed?
- What became stale?
- What conflicts?
- What evidence supports the current view?
- What should the existing Global C0 be able to recover safely from Navigator substrate?

## Core Law

**Navigator observes, maps, routes, validates, and prepares bounded evidence-addressable context. It does not author Elyxion, self-canonize material, replace specialized channels, or duplicate Global C0.**

Dream flow stays free:

creator dream / RAW → preservation → navigation metadata → specialist channels → later canonization / execution

Navigator must never turn this into:

dream → forced analysis → forced structure → canon

## Primary Responsibilities

1. **Topology Map** — global map of channels, branches, stages, archives, governance, and execution surfaces.
2. **Provenance** — preserve where an artifact, claim, or relation came from.
3. **Status / Authority Radar** — keep lifecycle state, evidence state, authority, and readiness separate.
4. **Relation Graph** — confirmed relations are traversable; unresolved relations are visible but blocked as facts.
5. **Collision Radar** — surface conflicting scope/ownership/meaning without auto-resolving it.
6. **Freshness / Invalidation** — changed sources invalidate affected slices, not the entire project by default.
7. **Evidence Index** — map claims and navigation objects to durable evidence addresses.
8. **Bounded Context Assembly** — prepare small relevant context packs instead of full-history replay.
9. **Human "Where are we?" View** — explain current position plainly.
10. **Global C0 Substrate Preparation** — prepare reliable evidence-linked substrate for the existing Global C0.

- claim Global C0 authority.

## Explicit Non-Authority

Navigator does **not**:

- decide canon;
- rewrite RAW meaning;
- invent missing lineage;
- merge branches;
- execute game implementation;
- replace P/A/E or other specialist channels;
- auto-resolve collisions;
- traverse unresolved relations as facts;
- promote UNKNOWN into certainty;
- become or duplicate Global C0.

When information is missing, the correct output is **UNKNOWN / UNRESOLVED / NOT OBSERVED**, not invention.
