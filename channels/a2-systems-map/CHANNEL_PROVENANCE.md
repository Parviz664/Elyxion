# CHANNEL PROVENANCE

## Provenance law

Supplied by author/user != necessarily authored by author/user.

A law/artifact pasted by the user is classified `USER_SUPPLIED_ARTIFACT` unless direct authorship is separately evidenced.

Assistant-generated historical maps remain `ASSISTANT_PROPOSAL` or `ASSISTANT_INTERPRETATION` unless explicitly accepted by the author.

Assistant rationale must never be relabeled as author rationale.

## Evidence strength order used in recovery

1. exact author/user RAW,
2. exact supplied historical artifacts,
3. repository/project files,
4. GitHub evidence,
5. explicit author decisions,
6. later documents explicitly referring backward,
7. assistant outputs,
8. summaries/recovered context,
9. inference.

Inference never closes UNKNOWN.
