# HISTORICAL_REASONING_PROTOCOL

PAE must reason historically, not flatten all artifacts into one timeless architecture.

## Rule 1 — build a local timeline first

For each channel:
birth evidence
→ version states
→ explicit supersessions
→ reversals
→ current local recovery state.

## Rule 2 — then build cross-channel chronology

Compare dated events across channels.

Example already observed:

A0 v4.1 on 2026-03-09 morning:
adult route A_ULTRA -> A0 -> E0;
A1/A2/A3 marked legacy/recovery.

Later A3 evidence:
2026-03-09 A2 v2.0/v2.1 admissibility evolution;
2026-03-09 A3 v2.0;
2026-03-11 A3 v2.2;
adult topology includes A1 -> A2 -> A3 -> E0.

Correct interpretation:
A0's local recovery can be historically correct while no longer globally latest.

Forbidden interpretation:
"A0 is wrong."

## Rule 3 — classify every conflict

Conflict classes:

TEMPORAL_SUPERSESSION
different times; later evidence may supersede earlier.

LOCAL_SCOPE_DIFFERENCE
both can be true in different task/mode scopes.

ROLE_EVOLUTION
same channel changes responsibility.

NAMESPACE_REUSE
same name used for potentially distinct functional families.

REAL_CONTRACT_CONFLICT
two artifacts claim incompatible authority in overlapping time/scope.

PROVENANCE_CONFLICT
content agrees but authorship/authority attribution differs.

UNKNOWN_RELATION
evidence insufficient to determine relation.

## Rule 4 — do not invent supersession

Later timestamp alone is not always enough.

Require where possible:
- explicit supersedes field;
- later owner decision;
- contract topology that clearly replaces earlier path;
- cross-channel evidence plus scope consistency.

If absent:
CANDIDATE_SUPERSESSION or UNKNOWN.

## Rule 5 — preserve reversals

A reversal is valuable history.

Examples:
- E-Prime inside A3 -> E-Prime explicitly outside A3;
- A0 staged A1/A2/A3 route -> later direct E0 route;
- later A2/A3 architecture may reintroduce a full A chain.

Do not rewrite reversal into "the architecture always meant X."

## Rule 6 — preserve mistakes separately from evolution

An assistant execution bug is not a design version.
A design reversal is not necessarily an error.

Classify:
DESIGN_CHANGE
AUTHOR_CORRECTION
ASSISTANT_EXECUTION_ERROR
RECOVERY_CORRECTION
UNRESOLVED_CONFLICT.
