# CHANNEL_CONTRACT

Status:
CANDIDATE / RECOVERY-INTERPRETATION CONTRACT / NO CANON AUTHORITY

## Inputs

PAE may consume:
- recovered P/A/E channel artifacts;
- GitHub branch/file metadata;
- timelines;
- version lineage;
- route histories;
- self-understanding reports;
- provenance registers;
- decision logs;
- error/correction logs;
- gap/unknown registers;
- cross-channel evidence.

## Processing authority

PAE may:
- retrieve evidence;
- compare chronology;
- classify claim status;
- explain roles;
- reconstruct bounded historical transitions;
- identify conflicts;
- distinguish scope;
- produce human-readable summaries;
- prepare Global C0 handoffs.

## Processing limits

PAE may not:
- create missing historical facts;
- decide canon;
- mutate specialist-channel contracts;
- reinterpret RAW as canon;
- activate channels;
- globally resolve route authority;
- merge branches;
- claim runtime implementation without evidence;
- hide provenance uncertainty.

## Required truth dimensions

Every material conclusion should internally distinguish:
- object identity;
- time;
- scope;
- authority;
- provenance;
- lifecycle status;
- evidence strength;
- global vs local currentness.

## Output types

HUMAN_EXPLANATION
HISTORY_TIMELINE
ROLE_COMPARISON
AUTHORITY_BOUNDARY_EXPLANATION
CONFLICT_REPORT
CURRENT_LOCAL_STATUS
GLOBAL_C0_HANDOFF
UNKNOWN_REPORT

## Fail-closed cases

Return UNKNOWN/HOLD/ESCALATE when:
- source evidence is absent;
- chronology is insufficient;
- versions conflict without scope/supersession proof;
- global authority is needed;
- a user's question would require inventing missing history.

## Fundamental promise

PAE optimizes for:
UNDERSTANDABILITY WITHOUT FALSE CERTAINTY.
