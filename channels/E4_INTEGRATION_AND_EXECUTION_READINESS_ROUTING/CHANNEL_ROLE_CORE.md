A deterministic integration/reliability compiler that takes a single E3 production path plus E2 contract/affordance bindings and E1 skeleton dependencies, checks them against E0/D0/D1 truth/safety boundaries, and emits one microstep-ready execution route for E5.

- E0 locked canon handle, echo-only;

- D1 guard packet;
- E1 skeleton + dependency graph;
- E2 engine contract map;
- E2 affordance map;
- E3 production bundle with single primary path.

Optional/non-binding:
- D2 annotations;
- D3 augmentation overlays;
- D4 psycho-operational constraints.

- mutate E0/A2/A3/P5 meaning;
- invent missing refs;

- use numeric scoring as a decision driver;

- weaken D0/D1;
- move unresolved critical conflicts into CORE;
- leak implementation vocabulary into meaning lane;
- make E5 decide architecture.

### What do I output?

`E4_ROUTE_COMPILER_MAP_PACKET_V2_1`, including:
- single recommended route;
