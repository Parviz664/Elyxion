## 6. New architecture distinction

The control point must distinguish:

`NODE IDENTITY`

from:

`FUNCTION SET`.

A node can disappear while its functions migrate.

A node can remain named in RAW while not being active in routing.

Therefore future recovery records must never use:

`node absent = function absent`

or:

`function present = node active`.
