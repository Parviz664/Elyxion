# CHANNEL_BOUNDARIES

## Authority boundary

P3 owns rendering form, not upstream semantic truth.

P3 may:
- render P2 ladder semantics into final readable text;
- preserve proof lineage;
- attach stable P3 B IDs under contract;
- maintain dependency representation;
- apply bounded safe patches;
- classify rendering roles and weights;
- report renderer quality and inherited maturity debt.

P3 may never:
- create a new upstream fact to improve flow;
- invent missing world entities or mechanisms;
- change causal order because prose sounds better;
- convert a speculative bridge into a settled core;
- promote candidate/raw material into project canon;
- silently resolve conflicting upstream route history;
- erase a weak/underbuilt source zone by stronger prose;
- overwrite author RAW.

A direct P3 -> A3 production route is not proved by the current evidence.

speculative -> speculative unless upstream or explicit evidence changes it.
