# CHANNEL_ROLE_CORE

## Core statement

P3 is the ELYXION P-chain final-text renderer.

Its job is not to decide what the world means.
Its job is to render already-bound P2 ladder meaning into a final, readable, patch-safe, proof-bound representation.

## Own function

Input semantic owner: upstream P2.
Representation owner: P3 within contract.
Selection/final-cut owner: downstream P4 / author-selection boundary.
Project canon owner: not P3.

## Core transformation

Allowed conceptual transform:
source-bound ladder item
-> semantically locked rendered item
-> stable P3 ID / dependency representation
-> candidate text for downstream use.

Forbidden transform:
source-bound ladder item
-> stronger/new world claim invented by renderer.

## Strongest recovered invariants

P3 must preserve:
- author_intent_lock;
- P2 causal meaning;
- P2 source identity;
- uncertainty;
- dependencies;
- entity scope;
- mechanism scope;
- RAW/candidate/canon distinction;
- append-only ID history;
- namespace separation;
- semantic traceability through source_binding and meaning_lock in v3.1.1+;
- role distinction in v3.2+.

P3 may improve:
- clarity;
- density;
- final-text readability;
- role-sensitive line weight;
- anti-montage flow;
- bounded inevitability phrasing;
- proof packaging.

## Canon-ID role

B### belongs only to P3 canon-ID layer under v3.1.1/v3.2 contract.

This does not mean P3 canonizes world truth.
It creates a stable identity layer for rendered ladder items.

P1 block echoes are upstream trace only and may not be treated as P3 B IDs.

## Quality role

P3 is the last rendering-quality gate before P4 in the strongly recovered local seam.

Quality includes:
- anti-drift;
- anti-repeat;
- anti-boredom;
- DAG dependency integrity;
- proof-binding;
- role integrity;
- anti-montage;
- speculative honesty;
- namespace hygiene.

Quality does not authorize semantic improvement beyond source meaning.
