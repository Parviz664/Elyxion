## Source hierarchy applied

1. exact author RAW / explicit owner decision;
2. user-supplied historical artifacts;
3. project files;
4. GitHub history;
5. later user-supplied artifacts referring backward;
6. assistant-generated material;
7. summaries/recovered context;
8. inference.

Inference is never upgraded to fact.
