# ELYXION COSMOS LITE — Android v0.3-alpha

**Наш собственный** нативный Android-контроллер. Это исходный проект, **не APK** и не доказанное управление оригинальной Starve.io.

## Что реализовано в исходном коде

- Плавающий джойстик на `WindowManager.TYPE_APPLICATION_OVERLAY` с настоящими `MotionEvent` и указателем пальца.
- Две небольшие кнопки A/B; размер 65–125%, прозрачность 30–100%, джойстик слева/справа.
- Разделённые окна управления, чтобы остальные части экрана оставались доступными приложению ниже.
- Ручной запуск/остановка переднего сервиса через приложение, а также «Остановить» в уведомлении.
- **Родная тестовая сцена**: джойстик перемещает светящуюся точку, A собирает кристалл поблизости, B выполняет рывок. Передача внутри процесса `InputBus` — чистый тестовый интерфейс.
- **COSMOS Frankfurt Network Probe**: 12 последовательных HTTPS-запросов к нашему публичному `/api/echo`, P50/P95, вариация, число ошибок и экспорт текста JSON. Wi-Fi/мобильная сеть отмечается вручную.

## Чего нет

- **Нет ввода в Starve.io:** ни overlay, ни `InputBus` не инжектируют клавиши, жесты или скрипты в чужую игру. Кнопка в приложении только открывает официальный сайт во внешнем браузере.
- **Нет доказанного ускорения интернета:** HTTP-время ответа COSMOS Frankfurt — не игровой ping Starve.io и не измерение маршрута через Oracle.
- **Нет Oracle VM** в пакете; никакие существующие RED/WhiteLine сервисы не изменялись.
- **Нет готового APK в этом архиве**: в данной среде отсутствует Android SDK/Gradle, поэтому сборка, запуск и реальные касания ещё требуют Android Studio и устройства.

## Собрать APK с помощью Android Studio

1. Установить Android Studio с Android SDK Platform 35, Build Tools и JDK 17. Открыть папку `ELYXION_COSMOS_Android_v0.3` как проект.
2. Для сборки нужен Gradle 8.9. В архиве есть `gradle/wrapper/gradle-wrapper.properties`, но **нет бинарного `gradle-wrapper.jar`**. Если IDE не позволяет синхронизацию без wrapper jar, в терминале с установленным Gradle 8.9 выполнить `gradle wrapper --gradle-version 8.9` (генерирует wrapper), затем `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).
3. Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk` **после успешной сборки**. Установить его на Samsung обычным Android Studio Run или через `adb install` (с разрешения владельца телефона).
4. В приложении дать разрешение «Показывать поверх других приложений», нажать «Играть в наш Android-тест», подвигать джойстик, собрать кристалл кнопкой A, сделать рывок кнопкой B.
5. Скрыть геймпад кнопкой приложения или действием уведомления; проверь, что все плавающие окна исчезли. Разрешение всегда можно отозвать в настройках Android.
6. COSMOS Network: выполнить отдельные 12-запросные серии по Wi-Fi и мобильной сети, выбрать правильный тип подключения вручную, поделиться JSON-отчётом. Не делать выводы по одному измерению.

**Важно:** Android может ограничивать overlays на системных экранах и на отдельных версиях прошивки; отсутствие окна на конкретном телефоне требует практической диагностики.

## Собрать APK через GitHub Actions без Android Studio

1. Создать **отдельный** репозиторий GitHub для этого пакета (не использовать WhiteLine/RED и не менять Elyxion без согласованного переноса).
2. Загрузить содержимое этой папки **в корень** репозитория, включая `.github/workflows/build-apk.yml`.
3. В GitHub открыть **Actions → ELYXION COSMOS Android APK → Run workflow**.
4. При успешном результате загрузить артефакт `ELYXION-COSMOS-Lite-v0.3-debug-APK` и извлечь `app-debug.apk`, затем установить на Android.
5. Если сборка завершится ошибкой, приложить логи. Поскольку pipeline здесь не запускался, реальное получение APK пока не подтверждено.

## Проверенные части без Android SDK

- Чистая Java-математика джойстика, мёртвая зона 8.5%, ограничение диагонали, сброс.
- Передача осей и действий через `InputBus` (только внутри собственного приложения).
- P50/P95/mean absolute adjacent difference; пустые данные не превращаются в фальшивые метрики.
- XML-манифест и целостность файлов. Android Gradle compile, APK install, foreground service и наложение на реальном телефоне **ещё не проверены**.

## Принцип безопасности и честности

Не включать Accessibility Gesture Dispatch, инъекцию JavaScript, key events в стороннюю игру или VPN без отдельной оценки технической совместимости, правил Starve.io и явного запроса пользователя. Для будущего COSMOS оптимизатора допустимы только проверяемые сравнения одного и того же назначения по эквивалентным маршрутам, без обещаний «нулевого ping».

Официальные ссылки: [Starve.io Terms](https://starve.io/terms.html), [Android TYPE_APPLICATION_OVERLAY](https://developer.android.com/reference/android/view/WindowManager.LayoutParams), [Android SYSTEM_ALERT_WINDOW](https://developer.android.com/reference/android/Manifest.permission).

## Изолированная ветка для GitHub Actions

Пакет подготовлен также для ветки `experiment/elyxion-cosmos-android-apk-v03` репозитория Elyxion под `experiments/COSMOS-Android/`. Файл workflow хранится в `.github/workflows/cosmos-android-apk.yml` в корне *ветки*. Он запускается по `push` в эту ветку. `main` не меняется; PR не вливается автоматически.

Артефакт появится в Actions только если удалённая сборка фактически пройдёт. До завершения CI файл APK не считается созданным.
